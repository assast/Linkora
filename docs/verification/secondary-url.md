# 书签地址2与统一切换验收

日期：2026-11-02。对应 OpenSpec 变更：`add-bookmark-secondary-url`。

## 📝 变更摘要

- 修改文件：书签 Prisma 模型与新增迁移、API DTO/查询投影/写入白名单，Web 类型/共享状态/书签库/首页/编辑表单，以及相关测试、SQL 和 API 文档。
- 修改类型：新增可选地址2及浏览器统一地址偏好，现有接口增加可空的 `url2` 字段。
- 影响范围：新增、编辑、详情、列表、首页、导出和各书签访问入口。
- 风险等级：验证后为低风险；新代码需要先应用新增数据库迁移。

## 🎯 直接影响

- `url2` 非空时与原地址共用 HTTP/HTTPS、内网主机名和 4096 字符校验；空白归一化为 `null`。PATCH 省略表示保留，显式空值表示清空。
- 两个地址的校验参数集中在 `bookmarkUrlOptions`。显式将校验库原先默认的 2084 字符限制对齐到字段声明的 4096，两个字段均测试边界及超长拒绝。
- `Catalog` 统一投影和写入白名单包含 `url2`，现有书签接口、首页和 `formatVersion: 1` JSON 导出均完整返回两个原始保存值。
- `resolveBookmarkUrl` 统一决定访问地址；未配置地址2时，两种模式始终返回原地址。列表、卡片、首页、分类批量打开和编辑访问按钮均已接入，展示域名与目标一致。

## 🔗 间接影响

- 模式保存在独立本地键 `linkora.bookmark.addressMode`，只包含枚举值，不保存书签内容。刷新、站内导航及身份切换继续使用本机选择。
- 地址模式不加入数据查询键，不改写原始书签，不触发服务端偏好写入、访问记录或图标刷新，也不清空同页多选或更改分页筛选。
- 图标继续使用原地址及原有书签图标配置。实际列表和分类访问继续按原书签 ID 归集计数，访问记录失败不阻止打开；编辑按钮沿用原有链接行为。
- 新选择控件使用原生 `select`，工具栏允许换行以容纳窄屏布局，保留链接真实 `href` 与原有新窗口隔离。

## 🧱 数据与兼容性

- 新迁移为 `202611020001_secondary_url`，仅增加可空的 `bookmarks.url2 VARCHAR(4096)`，不回填或修改已有地址。
- Prisma 迁移与 `docs/SQL/变更记录/202611020001_secondary_url.sql` 一致，完整初始化 SQL 和迁移版本说明已同步。
- 在本次专用 PostgreSQL 17.11 实例中分别完成全量初始化、旧版本结构升级及四份迁移的结构对比。按列名比较列、类型、NULL、默认值、索引、约束和枚举；已有书签除新增 `url2: null` 外逐字段保持一致。
- 公开书签的两个地址均可被访客读取；显式和继承私密书签的两个地址均沿用授权过滤和导出确认。
- 旧请求可省略新字段，前端有效地址解析也兼容缺失的地址2。回退应用时可保留新增可空列及其中的数据。

## ⚠️ 验证边界

当前 macOS 无头 Chrome/WebKit 的模拟方向键无法改变原生 `select`，最小独立 HTML 页面也复现相同现象。浏览器用例因此通过 Tab 验证控件可达，用 Playwright 原生选项 API 验证选择效果；未将方向键自动化失败判定为应用缺陷，也未为此增加自定义键盘处理。

数据库结构对比使用 PostgreSQL 17.11；本轮未连接业务数据库或部署服务器。
