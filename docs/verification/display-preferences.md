# 显示偏好验证

日期：2026-11-02。

## 变更与影响

- 顶栏新增“显示设置”，书签与分类字号可分别设为 12–20 px，并在保存前预览。覆盖卡片、列表、首页快捷方式和最近收藏，以及分类树与收藏中的分类名称。
- 工作空间四个导航项可分别选择，总开关保留各项选择；关闭总开关或没有可见导航项时，同时移除侧栏分区标题和导航。分类树、顶栏设置入口继续可用。
- 沿用既有偏好接口：访客使用本地存储，所有者使用账号偏好。保存失败恢复原显示，保留草稿以便重试；取消修改不写入偏好。
- 私密数据授权、搜索、分类拖动和书签访问逻辑保持原有路径。导航隐藏仅控制展示，不改变权限。
