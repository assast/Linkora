## ADDED Requirements

### Requirement: 批量请求使用明确且受限的 ID 集合
系统 SHALL 仅接受所有者提交的明确书签 ID 集合，去重后数量为 1 至 100，不接受由客户端声明的“全部结果”替代 ID 校验。系统 MUST 校验每条书签、目标分类和标签归属。

#### Scenario: 集合包含无效项目
- **WHEN** 批量请求包含一条不存在或无权修改的书签
- **THEN** 系统拒绝整个请求，其他书签不发生变化

#### Scenario: 空集合或超限
- **WHEN** 客户端提交空集合或超过 100 个不同 ID
- **THEN** 系统返回参数错误，不执行批量处理

### Requirement: 批量预览只读并绑定内容修订
系统 SHALL 对全部批量操作及导出提供只读预览，返回实际 ID 数量、操作影响、私密/公开变化数量和当前内容修订号。预览 MUST 不修改业务内容或修订号，提交 MUST 重新验证预览依据。

#### Scenario: 预览后数据被修改
- **WHEN** 所有者预览一组操作后，任一内容写入改变内容修订号，再提交旧预览
- **THEN** 系统返回 409，原批量操作完全不执行，前端要求重新预览

### Requirement: 批量写入整体成功或整体失败
系统 SHALL 在完成全部校验后以一个数据库事务执行批量写入，成功响应包含实际处理数量。系统 MUST 不返回已部分应用的成功状态。

#### Scenario: 写入中途失败
- **WHEN** 批量事务在更新部分书签后遇到数据库错误
- **THEN** 全部更新回滚，书签、标签关联和内容修订号保持操作前状态

### Requirement: 批量移动重新计算继承状态
系统 SHALL 支持将选中书签移动到有效分类或未分类，保留每条书签自身的显式私密标志，按目标重新计算有效私密。

#### Scenario: 普通书签移入私密分类
- **WHEN** 所有者批量移动普通书签到私密分类
- **THEN** 全部选中书签继承私密，自身显式标志保持原值，访客后续查询不再包含它们

#### Scenario: 从私密分类移入普通分类
- **WHEN** 移动会公开仅继承私密的书签
- **THEN** 预览准确显示公开变化，系统仅在有效预览和明确公开确认后提交，显式私密书签仍保持私密

### Requirement: 批量标签具有明确的三种语义
系统 SHALL 支持添加指定标签、移除指定标签、替换全部标签，执行标签规范化与数量上限校验；未选中书签 MUST 不受影响。

#### Scenario: 为二十条书签添加标签
- **WHEN** 所有者选中 20 条书签并添加一个标签
- **THEN** 这 20 条书签保留原标签并增加新关联，重复关联不增加，其他书签保持不变

#### Scenario: 移除与替换
- **WHEN** 所有者分别执行移除指定标签或替换全部标签
- **THEN** 移除仅删除指定关联，替换将选中书签的标签集合设置为提交的规范化集合，允许替换为空集合

### Requirement: 星标支持设置与取消
系统 SHALL 支持对选中书签显式设置或取消星标，不改变分类、标签或私密标志。

#### Scenario: 批量取消星标
- **WHEN** 所有者对包含已星标和未星标书签的集合执行取消星标
- **THEN** 集合内全部书签不再星标，首页和星标筛选同步反映新状态

### Requirement: 批量私密不能绕过祖先
系统 SHALL 支持修改选中书签的显式私密标志，但 MUST 不改变祖先的私密属性或将仍有私密祖先的书签公开。取消私密会公开的项目必须执行公开变化确认。

#### Scenario: 取消显式标志但仍继承私密
- **WHEN** 所有者将私密分类内书签的显式私密设为 false
- **THEN** 预览说明其仍继承私密，提交后有效私密继续为 true，访客不可读取

### Requirement: 批量删除须确认明确范围
系统 SHALL 在删除前展示选中数量与不可恢复提示，并要求明确删除确认和有效预览。系统 SHALL 仅删除被确认的书签及其标签关联，不删除分类或未选中书签。

#### Scenario: 确认删除混合内容
- **WHEN** 所有者确认删除一组普通与私密书签，且预览仍有效
- **THEN** 整组书签在同一事务中永久删除，相关列表、计数和首页更新

#### Scenario: 取消删除
- **WHEN** 所有者在确认界面取消删除
- **THEN** 不提交删除请求，原书签数据保持不变

### Requirement: JSON 导出保留选中内容与分类引用
系统 SHALL 只允许所有者导出明确选择的书签，先通过 `EXPORT` 预览校验修订号，包含有效私密内容时要求额外确认。JSON MUST 包含格式版本、导出时间、选中书签、标签和必要分类祖先，保留显式私密标志，不包含账号凭据或未选中书签。

#### Scenario: 导出含私密书签
- **WHEN** 所有者确认包含私密内容的有效导出预览并提交
- **THEN** 系统返回可解析 JSON，书签分类引用完整、显式私密标志保留，导出不修改数据库内容或修订号

#### Scenario: 未确认私密导出
- **WHEN** 导出集合含私密内容但缺少所需确认
- **THEN** 系统不返回导出文件并提示需要确认
